## 3. PATHWAY AGENT SPECIFICATION

### Core Function
Maps mutations → biological pathways → drug targets → treatment predictions

### Pathways Implemented (8 Total)

| # | Pathway | Key Genes | Status | Drug Targets |
|---|---------|-----------|--------|--------------|
| 1 | EGFR Signaling | EGFR, KRAS, PTEN, TP53, PIK3CA | ✓ | EGFR, BRAF, MEK |
| 2 | TP53 Apoptosis | TP53, MDM2, BAX, ATM | ✓ | MDM2 |
| 3 | PI3K-AKT-mTOR | PIK3CA, AKT, PTEN, mTOR | ✓ | PI3K, AKT, mTOR |
| 4 | MAPK-ERK | KRAS, BRAF, MEK, ERK | ✓ | BRAF, MEK |
| 5 | Cell Cycle | RB1, CDK4/6, CDKN2A | ✓ | CDK4/6 |
| 6 | DNA Repair | BRCA1, BRCA2, ATM, MLH1 | ✓ | PARP |
| 7 | Wnt Signaling | APC, CTNNB1, GSK3B | ✓ | Tankyrase |
| 8 | RAS Pathway | KRAS, NRAS, NF1 | ✓ | KRAS, MEK |

### Input Format
```json
{
  "patient_id": "HCM-SANG-0524-C20",
  "driver_mutations": [
    {"gene": "TP53", "score": 0.85},
    {"gene": "ALK", "score": 0.92},
    {"gene": "PIK3CA", "score": 0.78}
  ]
}
```

### Output Format
```json
{
  "patient_id": "HCM-SANG-0524-C20",
  "affected_pathways": [
    {
      "pathway": "TP53_APOPTOSIS",
      "score": 0.92,
      "mutated_genes": ["TP53"],
      "description": "p53-mediated apoptosis and cell cycle control",
      "cancer_relevance": "High",
      "drug_targets": ["MDM2"]
    },
    {
      "pathway": "PI3K_AKT_MTOR",
      "score": 0.78,
      "mutated_genes": ["PIK3CA"],
      "description": "Growth and survival signaling pathway",
      "cancer_relevance": "High",
      "drug_targets": ["PI3K", "AKT", "mTOR"]
    }
  ]
}
```

### Scoring Algorithm
```
pathway_score = (gene_overlap / total_pathway_genes + mutation_frequency_weight) / 2

Where:
  gene_overlap = count of mutated genes in pathway
  total_pathway_genes = size of pathway
  mutation_frequency_weight = prevalence of mutation in dataset
  final_score = normalized to [0.0 - 1.0]
```
